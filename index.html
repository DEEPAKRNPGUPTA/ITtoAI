12-Week Build Journey

Open each week for learning topics, practical work and the weekly evidence to publish.

Week 01

Python for AI & Data

Refresh only what is needed to build.

Learn

  • Python essentials, functions, collections
  • NumPy, Pandas, Jupyter / VS Code
  • CSV/Excel data, missing values, filtering, grouping
  • Git + GitHub workflow

Build

Explore a retail sales and inventory dataset.

Week 02

Practical Math for ML

Understand the math—not a university math course.

Learn

  • Mean, median, variance, standard deviation
  • Probability and distributions
  • Correlation and covariance
  • Vectors, matrices, dot product
  • Loss, error and gradient intuition

Build

Visual Math-for-ML notebook using business data.

Week 03

Machine Learning Foundations

Features → model → prediction → evaluation.

Learn

  • Supervised vs unsupervised learning
  • Regression vs classification
  • Features, labels, train/test split
  • Overfitting, underfitting, leakage
  • Linear models and tree models

Build

First demand / inventory prediction model.

Week 04

Practical ML Engineering

Move from notebook experiment to a repeatable pipeline.

Learn

  • Preprocessing and feature engineering
  • Time/date features and lag features
  • MAE, RMSE, MAPE/WAPE
  • Cross-validation and model comparison
  • Save/load model and prediction pipeline

Build

Demand Prediction V1 with evaluation report.

Week 05

Retail Demand Forecasting

Project 1 begins.

Learn

  • Sales history, seasonality and trend
  • SKU/store demand behavior
  • Intermittent / sparse demand
  • Forecast horizon and business use
  • Shortage and overstock signals

Build

Retail demand forecast dashboard and model report.

Week 06

Inventory + Cost + Price + Margin

Turn prediction into a business decision.

Learn

  • Inventory position and days of supply
  • Cost, selling price and margin
  • Stockout vs overstock risk
  • Promotion / markdown concepts
  • Rules + ML working together

Build

Retail Inventory & Pricing Decision System.

Week 07

ML → Modern AI Bridge

Connect traditional ML with LLM systems.

Learn

  • NLP → tokens → embeddings
  • Sequence learning and attention
  • Transformer intuition
  • Pretraining and next-token prediction
  • Prompting and structured outputs

Build

Small demos explaining each concept visually.

Week 08

GenAI, Embeddings & RAG

Ground AI in business knowledge.

Learn

  • LLM API interaction
  • Embeddings and semantic similarity
  • Vector stores and retrieval
  • RAG architecture
  • Grounding, citations and evaluation

Build

Retail AI assistant using product / inventory knowledge.

Week 09

AI Tools & Enterprise Actions

Move beyond chat.

Learn

  • Function / tool calling
  • REST APIs and database tools
  • Structured tool schemas
  • MCP concepts
  • Security and permission boundaries

Build

AI assistant that can call inventory, forecast and price tools.

Week 10

AI Agents

Goal → reason → tool → act → observe.

Learn

  • Agent loop and planning
  • Tools, memory and context
  • Guardrails and failure handling
  • Human-in-the-loop approvals
  • When not to use an agent

Build

Inventory Decision Agent with approval checkpoint.

Week 11

Automobile Shop-Floor Inventory

Project 2: transfer the capability to manufacturing.

Learn

  • Production plan and BOM concepts
  • Parts consumption history
  • Work-floor stock requirement
  • Shortage risk and replenishment
  • Transfer / purchase recommendations

Build

Shop-Floor Parts Requirement Predictor.

Week 12

Agentic AI Pipeline + Capstone

Bring ML, AI, tools, rules and people together.

Learn

  • Event-driven AI workflow
  • ML prediction as a service/tool
  • Rules + AI decision support
  • Human approval and business action
  • Monitoring, audit trail and feedback

Build

End-to-End Agentic Inventory Pipeline.

Technology Responsibility

A core interview skill is explaining why a step uses ML, AI, deterministic logic or a human—not merely using AI everywhere.

📈 Machine Learning

Predict demand, requirements, probabilities and numeric/business outcomes from historical data.

🧮 Rules / Deterministic Code

Apply policy, thresholds, calculations, validations and business constraints consistently.

🤖 AI / Agent

Interpret context, plan, select tools, synthesize information and manage exception-heavy workflows.

👤 Human in the Loop

Approve financially important or uncertain actions and provide accountability where automation should not act alone.
